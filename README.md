# Escape-The-Underground
My first ever game - a C++ console/terminal-based game for my Programming Fundamentals class.
The game is simple. You are trapped - and you must fight to escape.
Inspired by Undertale and Dungeons & Dragons.

Code that controls colour formatting (`colour_test.cpp`, `terminal_colours.h`) was generated by ChatGPT. All other code and files were created from scratch by me.
